# Плагин Figma: перевод из Listing Suite → в макет

Последнее звено. Текст переводится в Listing Suite, а в макет его
кладёт этот плагин — REST API Figma на запись не умеет ни на одном
тарифе, это ограничение самой Figma.

## Установить (один раз)

Нужно приложение Figma (десктоп), не браузер.

1. Скачайте папку `figma-plugin` целиком — три файла: `manifest.json`,
   `code.js`, `ui.html`.
2. В Figma: меню **Plugins → Development → Import plugin from manifest…**
3. Укажите `manifest.json` из этой папки.

Плагин появится в **Plugins → Development → «Listing Suite: перевод
в макет»**. Он частный, в каталог Figma не публикуется.

## Применить перевод

1. В Listing Suite на экране «Контент → Перевод» — в списке отметьте
   товары (или откройте один товар и выберите язык) и раскройте
   **«Скопировать для плагина»**. Наведите на блок — справа сверху
   появится иконка «скопировать», нажмите её. В буфере — JSON
   только с переведёнными строками.
2. Откройте макет в Figma, запустите плагин и **вставьте** текст
   в поле. Разбор начинается сразу.

   Второй путь — **файл**: кнопка «Выгрузить для Figma» в списке
   (один файл на всё) или «Применить в Figma» внутри товара; в
   плагине его выбирают через «или файл». Нужен, если JSON очень
   длинный и с буфером неудобно.
3. Плагин покажет **план**: что заменит, что уже так, где слоя нет.
   Ничего ещё не изменено. Если пришёл язык, страницы которого
   в макете нет, — эти позиции откладываются и называются, остальные
   идут.
4. Посмотрите план. Нажмите **«Применить · N»**.
5. Отчёт — три числа:

   ```
   Заменено: 31
   Не найдено слоёв: 2
   Совпадает с текущим: 0
   ```

   **Второе число важнее первого.** Не нашёлся слой — значит
   структура макета на этой странице разошлась с английской, и об
   этом лучше знать сразу, а не через неделю по кривой карточке.
   Ненайденные перечислены с их `slot` — по нему видно, где искать.

Отменить применённое — обычным **Cmd+Z** в Figma.

### Модули A+

Модули (`carousel …`) в выгрузке идут под слотами вида
`B0G4S9SJ3M.A+d05#1.0`: ASIN, вариант (`d` — десктоп 2718 px,
`m` — мобайл 1398 px), порядковый номер. Плагин находит модуль
на языковой странице тем же правилом, что Listing Suite на
английской: по **подписи над модулем** («A+ Premium Content_<ASIN>»
или подпись товара без типа) и по **позиции** — ряды сверху вниз,
в ряду слева направо, внутри варианта. Имя самого модуля не
участвует: между языками они расходятся, позиция — нет.

Из этого два требования к языковой странице:

- над модулями должна стоять подпись товара — модуль без подписи
  плагин не привязывает и в плане покажет «слоя нет»;
- модули товара должны лежать в том же порядке, что на английской.
  Переставили один блок — сдвинется нумерация всех после него, и
  переводы встанут в соседние модули. План это покажет как замену
  с чужим текстом в колонке «сейчас» — читайте план, а не только
  итог.

## Первый запуск: сверить глазами

Плагин находит слой по `slot` — имени фрейма и пути в дереве
(`B0G4S9SJ3M.PT01#0.1.2`), и считает этот путь сам, так же, как
Listing Suite при чтении файла. Совпадение двух обходов проверено
тестом на одном дереве, но **на живом файле первый раз надо
посмотреть глазами**: разойдись они, переводы встанут не в те
строки — и это худший исход, потому что выглядит правдоподобно.

Как: взять **B0G4S9SJ3M**, немецкую страницу, скачать выгрузку DE,
открыть план в плагине и сверить каждую строку — колонка «сейчас»
должна быть немецким текстом того же смысла, что «станет» (там уже
лежит перевод Марии, поэтому большинство строк будет «уже так»).
Совпало по всем 33 — обходу можно доверять и на остальных.

## Чего плагин не делает

- **Не трогает картинки.** Только текстовые слои.
- **Не меняет шрифт и кегль.** Оформление задал дизайнер, плагин
  подставляет текст в готовое. Влезет ли — видно в Listing Suite
  до применения, там контроль длины.
- **Не создаёт слои.** Нет слоя с таким `slot` — сообщает, а не
  дорисовывает.
- **Не применяет молча.** Сначала план, потом кнопка, потом отчёт.
- **Не копирует макет на новую страницу.** Первая версия работает
  только с языковыми страницами, которые уже есть (сейчас 11).
  Копирование — следующий шаг: в файле есть изображения с
  отрицательными координатами, обрезанные рамкой, и при неточном
  копировании они сдвинутся.

## Когда плагин отказывается

| в плане | что значит | что делать |
|---|---|---|
| **слоя нет** | на языковой странице нет слоя с таким `slot` | сравнить структуру фрейма с английской страницей |
| **несколько слоёв** | два фрейма с одним именем на странице | переименовать лишний; плагин не выбирает «первый попавшийся» |
| **слоя нет** у слота `…A+d05#…` | над модулем нет подписи товара, или модулей у товара меньше, чем на английской | поставить подпись над модулями; сверить состав и порядок с UK/US |
| **смешанное оформление** | в одном слое разные шрифты или кегли | такой слой плагин не трогает — простая замена текста потеряла бы оформление; править руками |
| **имя фрейма с опечаткой** | на странице `BB0…`, в выгрузке `B0…` | слой найден и будет заменён; опечатку стоит поправить в Figma |
| файл выгрузки не совпадает с открытым | открыт другой файл Figma | проверить, тот ли файл |

## Что дальше

- Копирование английского макета на языковую страницу, если её нет
  (языковых макетов 11 на 84 возможные пары товар-язык).
- Публикация переводов через Google Drive, чтобы плагин забирал их
  кнопкой, без буфера. Забор напрямую из Listing Suite пробовали:
  приложение закрыто авторизацией Cloud, и плагин до него не доходит.
